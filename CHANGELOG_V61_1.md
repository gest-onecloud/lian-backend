# LiAn V61.1.0 — Unified Match Intelligence

V61.1 consolidates the planned V61.1/V61.2/V61.3/V62 architecture into one incremental release built on V61.0.

- Universal Match Resolver with ambiguity protection.
- Canonical match identity and prediction/evidence timeline endpoints.
- Multi-source/data-fusion architecture remains local-first and provenance-aware.
- Data-health endpoint for source freshness and failures.
- Background/Catch-Up, Calendar Safe, Adaptive Learning, AntiError, Cross-Competition, Post-Match and Progol retained.
- No historical prediction is overwritten.
- No result is used to create a pre-match prediction.
- No paid football API is required by the core runtime.

# LiAn V64.6.0 — Selector profesional de ligas

## Cambio
Se reemplazó la fila expansiva de chips de competencias por un selector flotante compacto tipo checklist.

## Comportamiento
- Botón único `Todas las ligas` cuando no hay filtro.
- Muestra el nombre de la liga cuando hay una selección.
- Muestra el número de ligas seleccionadas cuando hay varias.
- Panel flotante con lista desplazable.
- Búsqueda interna de ligas.
- `Todos`, `Limpiar` y `Aplicar`.
- Cierre al seleccionar una liga, al hacer clic fuera o con Escape.
- Responsive.

## No modificado
- API y proveedores.
- Calendario.
- Match Intelligence.
- Búsqueda de partidos.
- Motor predictivo V64.0.0.
- Ponderaciones y variantes.
- Base de datos.
- Lógica de filtrado existente.

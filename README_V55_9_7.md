# LiAn V55.9.8 — PROFESSIONAL HARDENING

Incremental release over V55.9.6.

## Purpose
Protect all validated features while hardening calendar navigation, prediction provenance, confidence semantics and commercial-readiness diagnostics.

## Calendar contract
Any selected historical/current date may be synchronized for fixtures. Historical calendar reads do not run result synchronization, calibration, repair or learning writes. The calendar is read-only with respect to learning.

## Prediction provenance
Finished matches use an immutable pre-match prediction if one exists. If not, the UI labels any reconstructed estimate as retrospective and excludes it from performance claims.

## Commercial safety
Confidence is explicitly labeled as model confidence, not historical accuracy. Accuracy is only meaningful with a verified sample and evaluation window. System audit exposes calibration readiness and data coverage.
